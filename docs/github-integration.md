# GitHub 연동 상태

## Remote 저장소

```bash
$ git remote -v
origin	git@github.com:cweedlee/codyssey-e1-1.git (fetch)
origin	git@github.com:cweedlee/codyssey-e1-1.git (push)
```

## ssh 연동 확인 

```bash
$ ssh -T git@github.com
Hi cweedlee! You've successfully authenticated, but GitHub does not provide shell access.
```
